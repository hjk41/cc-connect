# Security policy / 安全策略

This policy covers the maintained [hjk41/cc-connect fork](https://github.com/hjk41/cc-connect). Security fixes are applied to the latest `main`; older fork builds do not have a separate support commitment. Upstream releases and distribution channels are maintained by the upstream project.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/hjk41/cc-connect/security/advisories/new). Include the affected commit or version, agent/platform, reproduction steps, impact, and a minimal example with secrets removed. Coordinate disclosure with the maintainers while a fix is prepared.

Do not post API keys, bot tokens, private messages, or exploitable vulnerability details in public issues. Ordinary bugs and questions belong in [Issues](https://github.com/hjk41/cc-connect/issues).

## 安全漏洞反馈

本策略适用于 `hjk41/cc-connect` fork，安全修复优先落在最新 `main`；旧版构建没有独立维护承诺。上游发行渠道由上游维护。

请使用 [GitHub 私密漏洞报告](https://github.com/hjk41/cc-connect/security/advisories/new)，附上版本或提交号、Agent/平台、复现步骤、影响和脱敏后的最小示例。修复准备期间请与维护者协调披露时间。

请勿在公开 Issue 中发布密钥、Bot Token、私密聊天或可被利用的漏洞细节。一般 Bug 与使用问题请提交到本 fork 的 Issues。
